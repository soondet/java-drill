# Java Drill

Офлайн-тренажёр для подготовки к сеньорским собеседованиям по Java.
Один HTML-файл, без сборки и без сети: открывается двойным кликом в любом браузере.

## Что внутри

- **749 карточек** с интервальным повторением (Leitner), 541 термин, 212 разборов «на пальцах», 71 принцип
- **31 трёхмерный мир** — прогулка по концепциям от третьего лица: JVM, конкурентность, кэш CPU,
  Kafka, Kubernetes, репликация, индексы, HashMap изнутри, Spring-контейнер, JWT и другие.
  У каждого свой урок, ползунки «что если», живые показатели и спрятанный факт
- **Аркада Debug Run** — 8-битный платформер с вопросами вместо боссов
- **Дуэли** — те же вопросы у двоих на разных устройствах, обмен коротким кодом; живая гонка по WebRTC
- **Игровые режимы**: блиц, связи, сортировка, правда/ложь, порядок, угадай по схеме, аббревиатуры, найди баг
- Английская локализация, поиск по всему, экспорт и импорт прогресса

## Сборка

```bash
node build.js            # index.html + *.js  →  java-drill.html
node build.js --inline-en  # вшить английский внутрь (иначе i18n-en.js лежит рядом)
```

Распространяется один файл `java-drill.html`. Рядом с ним нужен `i18n-en.js`,
если английский не вшит.

## Структура

| файл | что |
|---|---|
| `index.html` | приложение: разметка, стили, вся логика, 3D-движок на чистом WebGL |
| `cards.js`, `cards-extra.js` | карточки |
| `quiz.js`, `more.js`, `notes.js`, `pics.js` | варианты, разборы, заметки, схемы |
| `terms.js`, `term-extra.js`, `more-term.js` | словарь терминов |
| `explainers.js`, `more-fp.js`, `basics.js` | объяснения «на пальцах» и для начинающих |
| `principles.js`, `bugs.js`, `tricky.js`, `tier.js`, `ord.js` | принципы, баги, каверзные вопросы, приоритеты |
| `i18n-en.js` | английские переводы контента |
| `build.js` | сборка в один файл |
