# Java Drill для Android

Те же файлы, что и сайт, упакованы в APK через [Capacitor](https://capacitorjs.com) 8.
Работает без интернета с первого запуска. Комнаты-поздравления в APK не входят.

## Собрать

```bash
cd android-app
npm install                     # один раз
export ANDROID_HOME=~/Library/Android/sdk
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home   # brew install openjdk@21
npm run apk                     # → android/app/build/outputs/apk/release/app-release.apk
```

`npm run apk` собирает `www/` из файлов сайта (`bundle.js`), копирует их в Android-проект и собирает подписанный релиз.
Нужны Android SDK 36 и JDK 21 (тулчейн плагинов Capacitor требует ровно 21).

## Новая версия

Перед сборкой увеличь `versionCode` и `versionName` в `android/app/build.gradle` — иначе телефон не поставит обновление поверх.
Прогресс при обновлении сохраняется.

## Ключ подписи

Лежит **вне репозитория** (репозиторий публичный): `~/.config/java-drill/release.jks` и `keystore.properties` с паролем.
Без него релиз соберётся неподписанным. **Потеряешь ключ — обновления поверх старой версии ставиться не будут**,
придётся удалять приложение (вместе с прогрессом). Сделай копию этих двух файлов.

## Что сделано под Android

| | |
|---|---|
| `app-native.js` | кнопка «Назад» (окно сценки → меню и окна → главная → второй «Назад» = выход), сохранение бэкапа через «Поделиться», светлые значки строки состояния |
| `bundle.js` | состав APK: всё, что подключает `index.html`, + ленивые скрипты; без комнат, инструментов сборки и service worker |
| `AndroidManifest.xml` | микрофон (тюнер, ответ голосом) — Android спросит разрешение при первом использовании |
| `res/values/` | тёмный фон под системными панелями и на заставке |
| `capacitor.config.json` | отладка WebView в релизе выключена |

Прогресс сайта и приложения — разные хранилища: переносится бэкапом (на сайте «Прогресс → сохранить», в приложении «загрузить»).
